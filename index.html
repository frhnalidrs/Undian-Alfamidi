Streamlit Deployment (streamlit.py)

File streamlit.py dan requirements.txt siap digunakan

Program undian telah dibuat dalam versi Python Streamlit (streamlit.py) dengan seluruh fungsionalitas:

  • Input puluhan ribu data dari Google Spreadsheet publik, Excel, CSV, teks manual, dan generator sampel.
  • Pengaturan Kategori Hadiah bulk & dropdown di panggung.
  • Tombol merah arcade untuk memutar undian dengan algoritma A-Res Weighted Sampling.
  • Tampilan sesuai jumlah pemenang: $\le 3$ pemenang di slot machine, $4-10$ via amplop vintage Alfamidi, dan >10 via tabel interaktif.
  • Ekspor laporan Excel.
Perintah Menjalankan: 
pip install -r requirements.txt
streamlit run streamlit.py
